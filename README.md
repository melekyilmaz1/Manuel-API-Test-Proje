# Manuel API Test & Jira Test Senaryoları Projesi

Bu repository, manuel test süreçleri ve API testlerinin düzenli bir yapıda saklanması, takibi ve versiyon kontrolünün sağlanması amacıyla oluşturulmuştur.

## 📂 Proje Yapısı

Proje içerisinde yer alan klasör yapısı ve içerikleri şu şekildedir:

```text
manuel-test-proje/
│
├── jira-test-cases/         # Jira'dan dışarı aktarılan test senaryoları ve raporлар (CSV/Excel)
├── postman-collections/     # Postman üzerinden export edilen API test koleksiyonları (.json)
└── README.md                # Proje hakkında bilgiler
🛠️ Kullanılan Araçlar ve Teknolojiler
Jira: Test senaryolarının yazılması, task takibi ve test yönetimi.
Postman: API uç noktalarının (endpoints) test edilmesi, isteklerin ve koleksiyonların yönetimi.
