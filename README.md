# Manuel API Test & Jira Test Senaryoları Projesi

“Kalite yalnızca yazılımdaki hataları bulmak değil; sistemin kararlılığını ölçmek, olası riskleri önceden görmek ve geliştirme sürecine değer katmaktır.”

Taskpro proje kapsamında yürüttüğüm kapsamlı Kalite Güvence (QA) ve test sürecini başarıyla tamamlamış bulunmaktayım.

Bu proje boyunca uyguladığım temel test yaklaşımları ve aşamalar:

Arayüz İşlevsellik Testleri (Frontend Functional Testing)

Arka Uç REST API Doğrulamaları (Backend REST API Testing)

Manuel Test Senaryo Tasarımı (Manual Test Design)

Gereksinim ve Risk Odaklı Testler (Requirement & Risk Based Testing)

Keşifsel Test Uygulamaları (Exploratory Testing)

Doğrulama Faaliyetleri (Validation Testing)

Sınır Değer Analizi (Boundary Value Analysis)

Olumsuz ve Yetkilendirme Testleri (Negative & Authorization Testing)

Hata Yönetimi ve Kalite Değerlendirmesi (Defect Management & Quality Assessment)

Çalışma süresince Postman, Swagger, Jira, Google Sheets ve Chrome DevTools araçları etkin bir şekilde kullanılarak test planlaması, senaryo koşumu ve hata raporlaması uçtan uca gerçekleştirilmiştir.

Proje Çıktıları ve Özet Metrikler:


📌 Kapsamlı Manuel Test Senaryoları ve Tasarımları

📌 %100 Test Koşum Oranı (Test Execution)

📌 Postman ile Oluşturulan REST API Test Senaryoları

📌 Detaylı Hata Bildirim Raporları (Defect Reports)

📌 Frontend ve Backend Seviyesinde Kalite Analizi

📌 Ürün Geliştirme ve İyileştirme Önerileri

```text
